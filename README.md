AI-Enabled Urban Digital Twin

Project Overview

The AI-Enabled Urban Digital Twin is a final-year BTech Computer Science and Engineering project focused on mobility simulation and what-if scenario analysis for a selected urban area.

The system aims to digitally represent an urban area's road network using GIS and spatial data, estimate mobility conditions, simulate infrastructure and traffic changes, and compare their impacts to support decision-making.

Core Objectives

- Represent a selected urban area using GIS data.
- Store and manage geographic information using PostgreSQL and PostGIS.
- Model roads and intersections as a weighted graph.
- Calculate routes using graph algorithms.
- Estimate or predict traffic and travel-time conditions.
- Simulate what-if mobility scenarios.
- Compare baseline and scenario outcomes.
- Provide impact analysis and decision support through an interactive dashboard.

Planned Scenarios

1. Road closure
2. Traffic increase
3. Parking facility addition
4. Emergency routing and temporary road closure
